## Что нужно сделать (из ClickUp)

Раздел **Profile**, 4 пункта: **Profile name**, **Avatar**, **Change
password**, **Logout**. Полные требования и тест-сценарии — см. ClickUp
(кратко): кликабельные пункты, загрузка текущих значений, валидация ввода,

logout — полная очистка сессии и блокировка защищённых экранов после выхода.

## Разбор API OpenWebUI (проверено по исходникам open-webui/open-webui)

В отличие от PRD-2692, этот раздел работает через **auth-роутер**, не через
user-settings:

- `POST /api/v1/auths/update/profile` — body `{ name, profile_image_url }`.
  Один эндпоинт обновляет и имя, и аватар одновременно (веб-клиент шлёт оба
  поля вместе — нужно сначала загрузить текущий профиль, затем мёржить
  изменение и отправлять оба поля).
  - `profile_image_url` — либо `http(s)://` ссылка, либо base64 data URI
    (`data:image/{png,jpeg,gif,webp};base64,...`). Загруженный юзером аватар
    веб-клиент кроппит до 250×250 перед отправкой.
  - **Security:** backend валидирует `profile_image_url` и отклоняет
    `data:image/svg+xml` и любые не-image data URI — в прошлом это была
    реальная stored-XSS уязвимость через это поле
    ([GHSA-6gh2-q7cp-9qf6](https://github.com/open-webui/open-webui/security/advisories/GHSA-6gh2-q7cp-9qf6),
    [GHSA-3wgj-c2hg-vm6q](https://github.com/open-webui/open-webui/security/advisories/GHSA-3wgj-c2hg-vm6q)).
    На клиенте тоже нельзя пускать SVG/произвольные MIME в аватар.
- `POST /api/v1/auths/update/password` — body `{ password, new_password }`
  (текущий + новый пароль).
- `POST /api/v1/auths/signout` — без тела; веб-клиент дополнительно чистит
  `sessionStorage` и localStorage-токен на клиенте.
- `GET /api/v1/auths/` — текущий session user (token, expires_at, профиль).

Источники: [routers/auths.py](https://github.com/open-webui/open-webui/blob/main/backend/open_webui/routers/auths.py),
[apis/auths/index.ts](https://github.com/open-webui/open-webui/blob/main/src/lib/apis/auths/index.ts),
[GHSA-6gh2-q7cp-9qf6](https://github.com/open-webui/open-webui/security/advisories/GHSA-6gh2-q7cp-9qf6),
[GHSA-3wgj-c2hg-vm6q](https://github.com/open-webui/open-webui/security/advisories/GHSA-3wgj-c2hg-vm6q)
